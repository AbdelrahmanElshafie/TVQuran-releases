# TV Quran — App Downloads

Test builds of the **TV Quran** Android app. The app's source code is private; this
repository only hosts the installable APK.

## Download

**➡️ [Download the latest APK](https://github.com/AbdelrahmanElshafie/TVQuran-releases/releases/download/tester/TVQuran.apk)**

This link always points to the newest test build, so it never changes.

## Install (Android)

1. Open the downloaded `TVQuran.apk` on your phone.
2. If prompted, allow your browser / Files app to *install unknown apps*.
3. **Uninstall any older "TV Quran" first** — these builds are signed with a test key and
   will not install over a different signature.
4. If Google Play Protect scans the file, that is normal — tap through to install.

Android only. The iOS version is a separate app and is not distributed here.
